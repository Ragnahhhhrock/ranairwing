## Flying

| Key | Action |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> or <kbd>W</kbd> <kbd>S</kbd> | Stick. Down pulls back and the nose rises. |
| <kbd>←</kbd> <kbd>→</kbd> or <kbd>A</kbd> <kbd>D</kbd> | Roll |
| <kbd>Q</kbd> <kbd>E</kbd> | Rudder |
| <kbd>=</kbd> / <kbd>-</kbd> | Throttle up and down (also <kbd>Page Up</kbd> / <kbd>Page Down</kbd> and <kbd>]</kbd> / <kbd>[</kbd>) |
| <kbd>G</kbd> | Gear up and down |
| <kbd>F</kbd> | Flaps: cycles half, full, up |
| <kbd>H</kbd> | Arrestor hook up and down |
| <kbd>B</kbd> | Speedbrakes |
| <kbd>Space</kbd> | Launch from the catapult, and wheel brakes on deck |
| <kbd>X</kbd> twice | Eject. The first press arms it for about a second and a half. |

## Starting and stopping

| Key | Action |
|---|---|
| <kbd>R</kbd> | Restart on the catapult |
| <kbd>T</kbd> | Start an approach, 1.2 nm astern |
| <kbd>U</kbd> | Start the guided tutorial |
| <kbd>Enter</kbd> | Next lesson, when a lesson has finished |
| <kbd>Esc</kbd> | Leave the tutorial |
| <kbd>M</kbd> | Sound on and off |
| <kbd>L</kbd> | Raise or lower the aft lift. Locked out while aircraft are airborne. |

## Cameras

Keys <kbd>1</kbd> to <kbd>7</kbd> select Orbit, Deck, Island, Approach, Flyby, Cockpit and Chase. <kbd>C</kbd> switches between cockpit and chase. In the orbit-type cameras, drag to look and scroll to zoom. More in [seven cameras and when to use each](/blog/seven-cameras/).

## Hints

- <kbd>G</kbd> only moves the gear when you are airborne. It does nothing on the deck.
- <kbd>Space</kbd> is both the launch key and the wheel brakes. On the catapult it launches once the engine is at full power; below that the sim reminds you to run up first.
