# RAN Air Wing style guide

Derived from the sim's own interface (`index.html`). There was no written guide, so this one records what the sim already does. Blog, social images and any future pages follow it.

## Visual

| Role | Value |
|---|---|
| Background | `#0b1622` |
| Panel fill | `rgba(8,18,28,.62)` with 1px border `rgba(200,220,235,.18)`, radius 3px |
| Text | `#e8eef2` |
| Muted text | `#9fb4c2` (secondary), `#8fa6b5` (labels) |
| Accent (links, active, calls to action) | `#e8c547`; hover `#f3d86b`; text on accent `#10202c` |
| Success | `#5dff8f` |
| Warning / note | `#ff9a8c` |
| Type | `ui-monospace, "SF Mono", Menlo, Consolas, monospace`; body 15px / 1.7 on the blog, 12px in the sim HUD |
| Tracking | `.04em` body, `.12em`-`.16em` uppercase for headings and labels |
| Radius | 2-3px. No pills, no gradients, no drop shadows beyond a 1px text shadow over imagery |

Rules: dark background only; one accent colour; uppercase tracked labels for categories and metadata; key presses are shown as `<kbd>` in the accent colour; images are sim screenshots with a one-line caption stating camera, time and sea state.

## Voice

- Plain, factual, Australian English (colour, metre, programme, defence).
- Written by a builder, not a brand: "I", "we" sparingly, never hype ("amazing", "epic").
- Say what is known, what is approximated, and what is not yet built. Mark approximations the way the sim notes do.
- Dates, names, figures and units are given exactly or not at all. Metric first with knots for speed; feet for altitude as the aircraft's instruments read.
- History claims need a source in the post's **Sources** list. Unsourced claims are cut.
- Respect the people. HMAS Melbourne's crews and the 1964 and 1969 collisions are told with care, not as spectacle.
- Short paragraphs. One idea each. Headings only when a post is longer than about 400 words.

## Imagery and rights

- Only screenshots from the sim, and original diagrams. Photographs in the reference folder belong to their owners (Australian War Memorial and others) and are not republished.
- Every post has a hero screenshot. Alt text describes what is visible, not the keyword.

## Post template

Title (sentence case, under 70 characters) / one-line summary (under 160) / hero screenshot + caption / body / "Fly it" call to action when relevant / Sources (history posts) / share buttons / category tags.
